# Shape Spider — 게임 룰

> 이 문서가 게임 룰의 최종 기준이다. 기획서와 충돌하면 이쪽을 따른다.

**표기**
`[확정]` 결정 완료 · `[잠정]` 기본값으로 진행하되 플레이 테스트 후 재검토 · 표기 없음은 기획서 명시 사항

---

## 보드

- 10×10 격자
- `[잠정]` 10×10로 시작한다. 확대는 난이도 파라미터로 조정
- 좌표는 좌상단 `(0,0)`, `r` = 행, `c` = 열
- 게임 시작 시 모든 칸이 비어 있다
- 각 칸은 비어 있거나 하나의 색을 가진다

## 도형 카드

- 4색 폴리오미노 (테트리스형)
- `[잠정]` 도형은 회전이 가능합니다. 원하는 대로 배치합니다. 반전은 안됩니다.
- `[잠정]` 카탈로그 22종 — 2칸 1종(D2) + 3칸 2종(I3, L3) + 4칸 7종(I, O, T, S, Z, J, L) + 5칸 펜토미노 12종
  반전이 없으므로 S/Z, J/L이 서로 다른 도형으로 의미를 가진다. 6칸 이상 도형은 쓰지 않는다
- `[잠정]` 칸 수별 비율 — 2칸 10% · 3칸 20% · 4칸 35% · 5칸 35% (색상당 35장 기준 4 · 7 · 12 · 12장)
  같은 칸 수 안에서는 도형을 고르게 돌아가며 넣는다
- `[잠정]` 덱 총량 — 색상당 35장, 총 140장 (평균 약 3.9칸, 목표 3~6 기준 소요 칸수 86칸의 약 1.6배)
- 색상별 도형 분포는 동일하게 구성한다

## 덱과 제시

- 게임 시작 시 덱의 순서가 고정된다
- 덱에서 5장을 손패로 제시한다
- `[확정]` **유저는 손패 중 원하는 것만 배치한다.** 하나도 쓰지 않고 넘겨도 된다
- `[잠정]` **손패는 5장 단위로 통째 교체한다.** 넘기면 남은 카드가 전부 미사용 더미로 가고 새 5장이 제시된다
- 넘긴 도형은 **원래 덱 순서를 유지한 채** 미사용 더미에 보관된다
- 덱이 소진되면 **재구성**한다 — 사용한 도형만 빠지고, **남은 도형은 원래 순서 그대로** 처음부터 다시 제시된다. 섞지 않는다
- `[확정]` **재구성 1회마다 점수가 깎인다.** 많이 넘길수록 덱이 빨리 소진되어 재구성이 잦아진다
- `[잠정]` 재구성 횟수에 상한은 없다. 감점이 억제 역할을 한다
- `[잠정]` **무한 반복 방지** — 재구성 이후 한 바퀴 도는 동안 도형을 **한 장도 배치하지 않고** 다시 재구성에 도달하면 막힘으로 종료한다

## 배치

- 드래그 앤 드롭으로 배치한다
- 도형 전체가 판 안에 들어와야 하며, 이미 채워진 칸과 겹칠 수 없다
- **배치한 도형은 이동하거나 회수할 수 없다**
- `[잠정]` 정사각형 추출로 생긴 빈 칸에 **다시 배치할 수 있다.** 빈 칸은 빈 칸으로만 취급한다

## 정사각형 완성과 수집

- 같은 색 칸으로 이루어진 정사각형을 수집함에 넣는다
- 색상별로 3×3 → 4×4 → 5×5 → 6×6 순서로 넣어야 한다 (`[잠정]` 기본 목표 범위 3~6)
- `[확정]` 판정은 **색만** 본다. 도형의 경계는 무시하며, 여러 도형에 걸쳐 있어도 무방하다
- `[확정]` 뽑을 크기는 그 색의 다음 목표로 고정된다. 유저가 정하는 것은 **위치뿐**이다
- `[확정]` 추출한 칸만 비워지고, 나머지 칸은 판에 그대로 남는다
- **추출한 정사각형은 판으로 되돌릴 수 없다** (되돌리기 사용 시 제외)

## 보관함

- `[잠정]` **1차 구현에서 제외한다.** 플레이 테스트 후 도입 여부를 결정한다
- 도입 시 적용할 안
  - 한 번에 한 조각만 보관한다
  - 넣을 때는 연결된 같은 색 덩어리가 **통째로** 들어간다 (크기 선택 불가)
  - 모양이 단정하도록 직사각형 덩어리만 허용하는 안도 검토 중
  - 판에 되돌려 놓을 자리가 없어 영구 손실되는 경우의 처리 필요
  - 보관함에서 도형을 뺀 순간 해당 보관함은 잠깁니다.
    - 잠긴 보관함은 10x10 메인 판에 도형을 3개를 올리면 다시 열리도록 합니다.
    - 이는 난이도에 따라 다릅니다. -> 초급 쿨타임 : 0, 중급 쿨타임 : 1, 어려움 쿨타임 : 3
  - 보관함은 2개 고정합니다.

## 되돌리기

- `[확정]` **1단계만** 제공한다 (직전 조작 1회)
- `[확정]` 연속 사용 불가. 되돌린 뒤 새 조작을 해야 다시 쓸 수 있다
- `[잠정]` 되돌릴 수 있는 조작은 **도형 배치 1회**와 **정사각형 추출 1회**뿐이다
- `[잠정]` **손패 넘기기는 되돌릴 수 없다.** 넘기는 순간 다음 5장이 공개되므로,
  되돌리기를 허용하면 다음 카드를 본 상태로 판단하게 되어 정보 이득이 생긴다
- `[잠정]` 새 카드가 제시되면 그 이전 조작의 되돌리기 기록은 사라진다

## 점수

- `[확정]` **점수제다.** 목표를 전부 완성하지 못해도 게임은 성립하며, 완성한 만큼 점수를 얻는다
- `[확정]` 목표를 **전부 완성하면 압도적인 보너스**를 받는다
- `[확정]` **덱 재구성 1회마다 감점**된다
- `[잠정]` 정사각형 배점은 `칸 수 × 10` — 3×3 = 90, 4×4 = 160, 5×5 = 250, 6×6 = 360
- `[잠정]` 재구성 감점은 회차와 무관하게 **-50 고정** (누진 없음)
- `[잠정]` 전량 완성 보너스 **+2000** (목표 3~6 기준 기본 점수 합계의 약 60%)
- `[잠정]` 총점 하한은 0이다. 음수로 내려가지 않는다
- `[잠정]` 되돌리기 사용에는 감점이 없다. 오조작 구제가 목적이다
- `[잠정]` 감점 기준은 **재구성 횟수뿐이다.** 손패 넘기기 자체는 무료이며,
  많이 넘길수록 재구성이 빨라지는 방식으로 간접 반영된다
- 모든 수치는 `GameConfig.scoring`에서 읽는다. 하드코딩하지 않는다

## 게임 종료

- **승리** — 모든 색의 목표 정사각형을 전부 완성. 압도적인 보너스 점수
- **막힘** — 덱에 남은 **모든** 도형(미사용 더미 포함)을 판의 어느 위치에도 놓을 수 없고,
  추출 가능한 정사각형도 없는 상태
  > 손패를 그냥 넘길 수 있으므로, "손패에 놓을 도형이 없음"은 막힘이 아니다
- **정체** — 위 「덱과 제시」의 무한 반복 방지 조건에 걸린 경우
- `[잠정]` 유저가 직접 게임을 포기하고 종료할 수 있다. 그때까지의 점수가 최종 점수가 된다
- 어느 쪽으로 끝나든 그때까지의 점수가 최종 점수가 된다

## 난이도

난이도는 아래 파라미터로 조정한다. 모든 값은 `GameConfig`에서 읽는다.

- 목표 정사각형 크기 범위 — `[잠정]` 기본 `3~6`. `3~8`은 상위 난이도
- 등장 색상 수 — 기본 4
- 보관함 유무 — `[잠정]` 1차 구현에서는 없음
- 도형 복잡도 — 카탈로그에서 사용할 도형 종류
- 판 크기 — 기본 10×10
