## 보드

- 10×10 격자. `[미정]` 확대 여부 검토 중
- 좌표는 좌상단 `(0,0)`, `r` = 행, `c` = 열
- 게임 시작 시 모든 칸이 비어 있다
- 각 칸은 비어 있거나 하나의 색을 가진다

## 도형 카드

- 4색 폴리오미노 (테트리스형)
- `[미정]` 카탈로그 확정 — 칸 수 범위, 도형 종류, 색상별 분포
- `[미정]` 회전 / 반전 허용 여부
- `[미정]` 덱 총량 — 목표 달성에 필요한 총 칸수 이상이어야 한다 (`GAME_DESIGN.md` 8절 참조)

## 덱과 제시

- 게임 시작 시 덱의 순서가 고정된다
- 덱에서 5장을 손패로 제시한다
- `[확정]` **유저는 손패 중 원하는 것만 배치한다.** 하나도 쓰지 않고 넘겨도 된다
- 넘긴 도형은 **원래 덱 순서를 유지한 채** 미사용 더미에 보관된다
- 덱이 소진되면 **재구성**한다 — 사용한 도형만 빠지고, **남은 도형은 원래 순서 그대로** 처음부터 다시 제시된다. 섞지 않는다
- `[확정]` **재구성 1회마다 점수가 깎인다.** 많이 넘길수록 덱이 빨리 소진되어 재구성이 잦아진다
- `[확인]` 손패 5장 중 일부만 쓴 경우, 남은 카드는 넘길 때 함께 미사용 더미로 가는가(5장 단위 교체),
  아니면 손패에 남고 쓴 만큼만 보충되는가
- `[미정]` 재구성 횟수 상한 — 아무것도 배치하지 않으면 같은 순서가 무한히 반복될 수 있다

## 배치

- 드래그 앤 드롭으로 배치한다
- 도형 전체가 판 안에 들어와야 하며, 이미 채워진 칸과 겹칠 수 없다
- **배치한 도형은 이동하거나 회수할 수 없다**
- `[미정]` 정사각형 추출로 생긴 빈 칸에 다시 배치할 수 있는가

## 정사각형 완성과 수집

- 같은 색 칸으로 이루어진 정사각형을 수집함에 넣는다
- 색상별로 3×3 → 4×4 → 5×5 → 6×6 → 7×7 → 8×8 순서로 넣어야 한다
- `[확정]` 판정은 **색만** 본다. 도형의 경계는 무시하며, 여러 도형에 걸쳐 있어도 무방하다
- `[확정]` 뽑을 크기는 그 색의 다음 목표로 고정된다. 유저가 정하는 것은 **위치뿐**이다
- `[확정]` 추출한 칸만 비워지고, 나머지 칸은 판에 그대로 남는다
- **추출한 정사각형은 판으로 되돌릴 수 없다** (되돌리기 사용 시 제외)

## 보관함

- `[미정]` **도입 여부 자체가 미정이다**
- 논의된 안
  - 한 번에 한 조각만 보관한다
  - 넣을 때는 연결된 같은 색 덩어리가 **통째로** 들어간다 (크기 선택 불가)
  - 모양이 단정하도록 직사각형 덩어리만 허용하는 안도 검토 중
- `[미정]` 꺼내는 조건, 회전 허용 여부
- `[미정]` 판에 되돌려 놓을 자리가 없어 영구 손실되는 경우의 처리

## 되돌리기

- `[확정]` **1단계만** 제공한다 (직전 조작 1회)
- `[확정]` 연속 사용 불가. 되돌린 뒤 새 조작을 해야 다시 쓸 수 있다
- `[미정]` "1개 조작"의 단위 — 도형 배치 1회 / 정사각형 추출 1회 / 손패 넘기기 1회
- `[미정]` 새 카드가 제시된 뒤에도 그 이전 조작을 되돌릴 수 있는가
  허용하면 다음에 올 카드를 본 상태로 되돌리게 되어 정보 이득이 생긴다. 막는 편을 권장

## 점수

- `[확정]` **점수제다.** 목표를 전부 완성하지 못해도 게임은 성립하며, 완성한 만큼 점수를 얻는다
- `[확정]` 목표를 **전부 완성하면 압도적인 보너스**를 받는다
- `[확정]` **덱 재구성 1회마다 감점**된다
- `[미정]` 정사각형 완성 배점 — 크기별 차등 여부 (8×8이 3×3보다 높은가)
- `[미정]` 재구성 감점 폭. 회차가 늘수록 감점이 커지는 누진 방식인지
- `[미정]` 승리 보너스의 크기
- `[미정]` 점수 하한 (음수 허용 여부)
- `[미정]` 되돌리기 사용에도 감점이 있는가
- `[확인]` 감점 기준이 **재구성 횟수**인지, **손패를 넘긴 횟수**인지
  현재는 재구성 기준으로 기재했다. 넘기기 자체는 재구성을 앞당기는 방식으로 간접 반영된다

## 게임 종료

- **승리** — 모든 색의 목표 정사각형을 전부 완성. 압도적인 보너스 점수
- **막힘** — 덱에 남은 **모든** 도형(미사용 더미 포함)을 판의 어느 위치에도 놓을 수 없고,
  추출 가능한 정사각형도 없는 상태
  > 손패를 그냥 넘길 수 있으므로, "손패에 놓을 도형이 없음"은 막힘이 아니다
- 어느 쪽으로 끝나든 그때까지의 점수가 최종 점수가 된다
- `[미정]` 재구성 횟수 상한에 도달했을 때 종료시키는가
- `[미정]` 유저가 임의로 게임을 포기하고 종료할 수 있는가

## 난이도

난이도는 아래 파라미터로 조정한다. 모든 값은 `GameConfig`에서 읽는다.

- 목표 정사각형 크기 범위 (`[미정]` 기본값 — `GAME_DESIGN.md` 8절에서 `3~6` 검토 제안)
- 등장 색상 수
- 보관함 유무
- 도형 복잡도
- 판 크기
